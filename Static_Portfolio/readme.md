STATIC PORTFOLIO WEBPAGE - HTML/CSS:

Project Overview
The Portfolio Webpage is a simple static website created using HTML and CSS to showcase personal information, skills, projects, and contact details. The main purpose of this project is to present a clean and professional online identity that can be shared with others.
This web page does not use any back-end or database. All the content is displayed directly on the browser using static files. The design focuses on simplicity, easy navigation, and responsiveness. The portfolio can be used by students, beginers, or professionals to highlight their achievements and work.

Key Features:
Clean and modern layout
Sections like Home, About, Skills, Projects, and Contacts
Fully static, no server or database required
Designed using standard HTML5 and CSS3
Responsive design that adjusts to different screen sizes
Easy to update and maintain

Development Process
1. Planning the Structure
Decided what sections the portfolio will include (Home, About, Skills, Projects, Contact).
Created a rough layout/wireframe to understand how the webpage should look.
Identified content such as profile image, text, project descriptions, and links.

2. Setting Up the Project
Created a new folder in VS Code for the project.
Added files:
index.html (main webpage)
style.css (stylesheet)
assets/ folder for images (if used)

3. Building the HTML Structure
Wrote HTML5 boilerplate code.
Added semantic elements:
<header> for navigation
<section> for each page part
<footer> for contact info
Inserted content like headings, paragraphs, images, buttons, and links.
4. Designing with CSS
Connected style.css to the HTML file.
Applied basic styling
Colors, fonts, spacing, margins, and padding
CSS Flexbox for layout alignment
Background colors and hover effects for buttons/links
Added responsive CSS using media queries to make it mobile-friendly.

5. Testing and Debugging
Opened the webpage in a browser to check layout and design.
Fixed issues like incorrect alignment, spacing problems, or font sizes.
Ensured all links, buttons, and images worked properly.

6. Final Review
Cleaned the code for readability.
Added comments in CSS and HTML for understanding.
Verified that the final design looks professional and consistent.
